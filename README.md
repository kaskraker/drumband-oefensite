# Oefensite Drumband Ingelmunster

Statische oefensite voor de leden van de drumband en de kleine trommelaars (Kunst Veredelt Ingelmunster).

- `index.html` bevat de pagina en de lijst met stukken
- `files/` bevat partituren (PDF) en audio, per stuk
- `video/` bevat de Samba Queen-videolessen

Geen build nodig: de map kan rechtstreeks op Netlify of Cloudflare Pages gezet worden (publish directory: de hoofdmap).
